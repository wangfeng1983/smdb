## 实施优先级

### 高优先级（核心功能）

#### 1. 内存管理器（MemManager）

**文件：** `src/storage/mem_manager.cpp`

**核心功能：**
- 页分配器（8KB页）
- 槽分配器
- 地址转换
- 空间管理（Control, Table, Index, Undo, Redo）
- 脏页跟踪
- 统计信息

**关键算法：**
- Buddy分配器
- 空闲链表管理
- LRU页缓存

**测试要点：**
- 页分配/释放正确性
- 地址转换准确性
- 内存泄漏检测
- 并发安全性

**预计工作量：** 3-5天

#### 2. 锁管理器（LockManager）

**文件：** `src/concurrency/lock_manager.cpp`

**核心功能：**
- 锁获取/释放
- 锁兼容性检查
- 等待图管理
- 死锁检测
- 超时处理

**关键算法：**
- 等待图遍历
- 死锁检测（深度优先搜索）
- 受害者选择

**测试要点：**
- 锁升级/降级
- 死锁场景
- 超时处理
- 并发压力测试

**预计工作量：** 2-3天

#### 3. 闩管理器（LatchManager）

**文件：** `src/concurrency/latch_manager.cpp`

**核心功能：**
- 共享/独占闩
- 自旋锁优化
- 读写锁

**关键数据结构：**
- 原子操作
- 自适应自旋

**预计工作量：** 1-2天

### 中优先级（数据管理）

#### 4. 表实现（Table）

**文件：** `src/core/table.cpp`

**核心功能：**

- 树平衡

**关键算法：**
- B+树插入
- B+树删除
- 范围扫描

**预计工作量：** 5-7天

#### 6. 哈希索引（HashIndex）

#### 8. 重做日志（RedoLog）

## 测试策略

### 单元测试

每个模块需要以下测试：

1. **正常路径测试**
   - 验证基本功能
   - 边界条件
   - 错误处理

2. **并发测试**
   - 多线程场景
   - 竞态条件
   - 死锁场景

3. **性能测试**
   - 基准测试
   - 内存使用
   - CPU使用

### 集成测试

测试模块间交互：

1. **Table + Index**
   - 插入自动更新索引
   - 删除自动更新索引

2. **Transaction + Lock**
   - 事务锁获取
   - 死锁检测

3. **Recovery + Persistence**
   - 崩溃恢复
   - 检查点

### 端到端测试

模拟真实场景：

1. **OLTP工作负载**
   - 大量小事务
   - 并发用户

2. **分析查询**
   - 大量扫描
   - 范围查询

3. **故障注入**
   - 进程崩溃
   - 磁盘故障
   - 网络故障
